CSOP ETP 管理後台

自行更新產品 ticker 與資料 · 直接寫回 GitHub Pages

① 連線設定（一次設定，之後自動記住）

僅用於呼叫 GitHub API。Token 只存在本機瀏覽器 localStorage，不會上傳到任何第三方。
建立方式：GitHub 右上角頭像 → Settings → Developer settings → Personal access tokens → 產生 token，勾選 repo（公開倉庫勾 public_repo 即可）。

② 編輯產品清單

Ticker Fund Name 類別 Synthetic 啟用
請先「儲存設定」並「讀取資料」。
• 類別：ETF 或 L&I（槓桿及反向）。 Synthetic：合成 ETF（交易所買賣基金）。
• 啟用：取消勾選可讓該產品從抽題池中隱藏（不下架資料，只是不抽）。
• 匯入 Excel：使用與原始 HR Excel 相同的格式（Table 1 = ETF、Table 2 = L&I），會以 Excel 內容整份取代目前清單。
資料來源：products.json · 儲存後約 1 分鐘 GitHub Pages 會自動重建，抽題網頁即生效。
